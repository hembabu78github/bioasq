# Stage 4 protocol note

## Retrieval model decision

BGE-small is the selected dense retriever for continued development because it
outperformed PubMedBERT in retrieval accuracy, latency, memory footprint and
corpus-encoding time on the Stage 3 development pilot.

BM25+BGE reciprocal-rank fusion remains the strong hybrid comparator and an
optional escalation route.

PubMedBERT is retired from the proposed system. Its development results remain
part of the transparent model-selection record.

## Risk-adaptive interpretation

The original query-only evidence-risk prior is not frozen. The Stage 4
retrieval-uncertainty score uses only deployment-available retrieval
diagnostics:

- BM25 margin;
- BGE margin;
- lexical/dense overlap;
- lexical/dense top-1 agreement.

The score is not a clinical harm score.

## Graph and verification pilot

The local graph is constructed only from retrieved evidence. Every edge must
retain evidence IDs and a supporting quotation.

The verification labels in Stage 4 are generated by the same model family and
are therefore not gold labels. They support pipeline debugging only. The
project will subsequently create an independently reviewed claim-verification
sample before claiming improved factual reliability.
