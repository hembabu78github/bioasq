# Frozen execution environment

The results reported in the associated manuscript were generated using
Python 3.11.9 on Windows with CPU-only execution.

- frozen_python_version.txt records the experimental Python version.
- requirements_frozen.txt records the exact experimental package freeze.
- requirements.txt provides bounded installation requirements for users.

Python 3.14.6 was tested only as a later local installation environment and
was not used to generate the reported manuscript results.
